# Кейсы TIMUR SEO

Публичный сайт с кейсами продвижения: https://tem11134v2-cmd.github.io/cases/

Репозиторий содержит **только собранный сайт**. Исходники кейсов, выгрузки Метрики и
Вебмастера и генератор лежат вне репозитория, в рабочей папке агентства, и наружу не публикуются.

## Как устроено

- `index.html` — список кейсов
- `cases/<slug>/index.html` — страница кейса
- `assets/img/<slug>/` — скриншоты сайта клиента: текущий и, где есть, снимок из Вебархива «до»
- `sitemap.xml`, `robots.txt`, `.nojekyll` — служебные

Страницы самодостаточны: весь CSS и JS внутри HTML, из внешних ресурсов только Google Fonts.
Графики — inline-SVG, данные захардкожены при сборке.

## Как обновлять

Файлы здесь **не редактируются руками** — они перезаписываются генератором.
Правка идет в исходный JSON кейса, затем пересборка и push.

## Индексация

Сейчас сайт закрыт от поисковых систем (`robots.txt` + `noindex`): ссылку можно отправлять
клиентам, но в выдачу сайт не попадает. Открывается одним флагом в генераторе.
